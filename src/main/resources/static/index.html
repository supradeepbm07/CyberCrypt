PROJECT OVERVIEW

CyberCrypt — Cyber Crime Complaint & Digital Evidence Management System

A Java-based academic prototype that centralizes cyber crime reporting, automated risk prioritization, secure evidence handling and investigator workflows in one auditable platform.

CORE SECURITYSHA-256 Evidence IntegrityUploaded evidence receives a cryptographic fingerprint so later changes can be detected.
SMART WORKFLOWRisk-Based PrioritizationIncident type, financial loss and emergency keywords contribute to a 0–100 risk score.
AUDITABILITYChain of CustodyImportant case and evidence actions are recorded in a hash-linked investigation history.
TECH STACKJava • Spring Boot • H2 • HTML • CSS • JavaScriptDesigned as a complete full-stack project for secure complaint and evidence management.
